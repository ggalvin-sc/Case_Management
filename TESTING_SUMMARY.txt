================================================================================
                    ROOT CAUSE ANALYSIS
================================================================================

Location: backend/server.js (Lines 1438-2654)

The Bug:
  38 instances of: const user = requireAuth(req, res);        [BROKEN]
  Should be:       const user = await requireAuth(req, res);  [CORRECT]

Why It Breaks:
  1. requireAuth() is async, returns Promise without await
  2. user = Promise object instead of user data
  3. Promise is truthy, so if (!user) passes
  4. user.role returns undefined (Promise.role)
  5. undefined !== 'admin' fails role checks
  6. Returns 403 or 404 even for valid requests
